# Diagnose SHK – GitHub Pages

## Auf dem iPhone
1. Repository auf GitHub anlegen.
2. Alle Dateien dieses ZIP-Archivs in das Repository laden.
3. Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. Die GitHub-Pages-Adresse in Safari öffnen.
5. Teilen → Zum Home-Bildschirm.

## Version 2
Die Anlage ist interaktiv. Bauteile können angetippt werden. Es gibt Messgeräte, Prüfungen, Diagnoseprotokoll, Fehlerfälle, Punkte, Timer und Anfänger/Schwer.

Die App läuft als statische Web-App ohne Server.
